# The Trust Network

A verified directory for small businesses — named owners, reviews tied to
real purchases, no paid rankings, ever.

**Live site:** https://tinglott.github.io/trust-network/

Every member starts unverified. The Verified mark appears only after a
person has run the full public checklist (see "How verification works" on
the site), and it means exactly: identity, storefront, and ownership were
checked on the date shown. It is not a guarantee of service quality, and
the network offers no insurance, protection plan, or coverage of any kind.

Distance search uses town-level ZIP centroids (data © GeoNames, CC BY 4.0).
A visitor's ZIP is typed by them and used only in their browser.
